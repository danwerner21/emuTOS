
Use this command line example to compile these BASIC programs
(the "C:\BASICEXA.MPL>" is printed by EmuTOS.)

C:\BASICEXA.MPL>  c:\HIBAS.210\HBASIC.TTP ASCIIART -Z+

Then to run the program:

C:\BASICEXA.MPL>  asciiart

Compiling and running these BASIC programs best done in
an 80x50 terminal window, as this matches the console
of an Atari ST in high resolution mode.

The disk image includes the STEVIE and UEMACS text editors
for creating your own BASIC programs.
